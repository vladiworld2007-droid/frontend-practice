# Frontend Practice

Учебный frontend-проект для практических и контрольных работ.

## О проекте

Проект создан для освоения основ HTML, CSS, Git, GitHub, Pull Request и GitHub Pages.

## Структура проекта

- `index.html` — главная страница
- `pages/about.html` — страница «О проекте»
- `pages/contacts.html` — страница «Контакты»
- `css/style.css` — стили сайта
- `images/` — изображения проекта

## Технологии

- HTML
- CSS
- Git
- GitHub

## Ссылка на сайт

Ссылка на опубликованный сайт будет добавлена после настройки GitHub Pages.
