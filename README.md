
# Frontend Practice

Учебный frontend-проект для практических и контрольных работ.

## О проекте

Проект создан для освоения основ HTML, CSS, Git, GitHub, Pull Request и GitHub Pages.

## Актуальность

Актуальность проекта обусловлена необходимостью освоения современных базовых инструментов веб-разработки. Навыки работы с HTML, CSS, системой контроля версий Git и платформой GitHub необходимы для разработки, сопровождения и совместного развития веб-проектов.

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлена форма оформления заявки, реализовано модальное окно, HTML5-валидация полей и обработка формы с помощью JavaScript.
- Практическая работа 4: выполнена реорганизация CSS, добавлены CSS-переменные, состояния интерактивных элементов (:hover, :focus-visible, :active, :disabled), стили валидации формы и улучшено оформление интерфейса.
