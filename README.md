# ТехноЛавка — доработка первого frontend-проекта (ПР №13–15)

Автор: Бережной Владимир Александрович, ЭФБО-10-25.

Основа: [frontend-practice](https://github.com/vladiworld2007-droid/frontend-practice/) — учебный магазин техники из КР №1, **без Bootstrap**. Архив предназначен для внесения изменений в этот же репозиторий. Платежей и серверной отправки заявок нет.

## ПР №13 — доступность (выделенные пункты)

- Смысловые изображения снабжены `alt`, у декоративных элементов применён `aria-hidden="true"`.
- Сохранены семантические `main`, `nav`, `header`, `footer`, заголовки и связанные с полями `label`.
- ARIA применяется точечно: `aria-current`, `aria-label`, `aria-labelledby`, `aria-live`, `role="status"`.
- Добавлены видимые состояния фокуса, ссылка пропуска к содержимому, восстановление фокуса после закрытия диалога.
- **Lighthouse не запускался в этой среде.** Для завершения выделенных пунктов ПР №13 нужно открыть сайт в Chrome → F12 → Lighthouse → Accessibility → Analyze page load и сохранить HTML-отчёт или скриншот в `lighthouse/`. Не выдавайте файл `STATIC_AUDIT.md` за Lighthouse.

## ПР №14 — адаптивность (выделенные пункты)

- Подключён `css/responsive.css` на всех шести страницах.
- Сетка, hero, навигация, каталог, формы и контакты адаптированы под ширины 360, 430, 768, 1024, 1440 px.
- Для карточек и крупных изображений подготовлены варианты PNG 480/960 px с `srcset` и `sizes`; SVG сохранён как fallback.
- Таблица характеристик размещена в контейнере с горизонтальной прокруткой.
- **Фактическую ручную проверку всех ширин в браузере следует выполнить через DevTools**; скриншоты реального тестирования не выдуманы.

## ПР №15 — JavaScript (выделенные пункты)

- `js/data.js`: объект `product` с типами `string`, `number`, `boolean`.
- `js/main.js`: арифметические операции, сравнения, `&&`, `!`, функции `formatPrice`, `calculateDiscount`, `getFinalPrice`, `getProductStatus`, `getShortDescription`.
- Результаты выводятся в консоль через `console.log` и `console.table`.
- На странице выводится сообщение через `textContent`, не через `innerHTML`.
- Сохранена работа существующего модального окна и демонстрационных форм.

## Важно о ресурсах

Исходные HTML-файлы были предоставлены пользователем. Оригинальные CSS/JS и SVG не были загружены отдельными файлами: структуру и стили сверили с открытым GitHub-репозиторием, а для самодостаточного архива **восстановлены совместимые CSS и векторные изображения**, не являющиеся побайтовыми копиями оригинальных ресурсов. При необходимости сохранить точный внешний вид прежнего сайта, лучше заменить `css/style.css` и `images/` оригинальными файлами из GitHub, оставив `css/responsive.css`, обновлённые HTML и JS.

## Как проверить и отправить

1. Распаковать архив, открыть `index.html` или запустить Live Server в VS Code.
2. Проверить консоль браузера: должна появиться группа `ПР №15 — демонстрация JavaScript` без ошибок.
3. Проверить кнопку «Заказать», закрытие по Esc, форму `order.html`, навигацию Tab.
4. Проверить мобильные ширины в DevTools и выполнить Lighthouse для `index.html`, `catalog.html`, `order.html`.
5. Сохранить настоящий отчёт в `lighthouse/`, затем загрузить файлы в репозиторий `frontend-practice` и сделать коммит.
