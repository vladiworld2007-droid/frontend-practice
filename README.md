# КР №1 — интернет-магазин ТехноЛавка

Многостраничный учебный сайт магазина техники и аксессуаров. Проект сделан на HTML, CSS и JavaScript без CSS-фреймворков. В нём отработаны семантическая разметка, навигация, формы, модальное окно, Flexbox, CSS Grid и именование классов по БЭМ.

## Страницы

- `index.html` — главная страница, преимущества и популярные товары.
- `catalog.html` — каталог с учебным блоком фильтров и карточками.
- `product.html` — описание наушников Sonic Pro и таблица характеристик.
- `order.html` — форма заявки с браузерной проверкой полей.
- `contacts.html` — контакты учебного магазина.
- `pages/about.html` — дополнительная страница о проекте.

## Запуск

Откройте `index.html` в браузере. Для публикации включите GitHub Pages для ветки `main`; после отправки и объединения изменений сайт будет доступен по адресу: https://vladiworld2007-droid.github.io/frontend-practice/

## Самостоятельные решения

- Сделан фирменный стиль магазина и собственные SVG-иллюстрации товаров.
- Добавлены шесть товаров, бейджи, оценки и категории.
- Созданы дополнительная страница о магазине, подробная страница товара и отдельная форма заявки.
- Фильтры и сортировка в каталоге оформлены как статический учебный интерфейс.
- Общая навигация и хлебные крошки связывают страницы; старый адрес `pages/contacts.html` перенаправляет на актуальную страницу контактов.
- Стили используют CSS-переменные, Flexbox, Grid, состояния наведения и фокуса, а также мобильные медиазапросы.
- JavaScript открывает и закрывает модальное окно, подставляет выбранный товар и проверяет формы средствами браузера. Данные формы никуда не отправляются.
- Добавлены Open Graph метаданные и карта сайта `sitemap.xml`.

## Практические занятия

- Практические 1–4: исходная база проекта — HTML-структура, оформление, форма с модальным окном и CSS-переменные.
- Практическое 5: многостраничная структура, единая навигация, хлебные крошки и метаданные страниц.
- Практическое 6: навигация и карточки на Flexbox, каталог на CSS Grid и блок фильтров.
- Практическое 7: БЭМ-именование компонентов в HTML и CSS; JavaScript использует отдельные `id` и `data-*` атрибуты.
- Практическое 8: итоговая проверка требований КР №1, README и подготовка проекта к публикации.
