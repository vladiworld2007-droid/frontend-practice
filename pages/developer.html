О разработчике

Разработчик проекта — Владимир Бережной.

Сайт разработан в рамках изучения дисциплины «Фронтенд и бэкенд разработка».

Используемые технологии

  • HTML — для создания структуры страниц;
  • CSS — для оформления пользовательского интерфейса;
  • JavaScript — для реализации интерактивных элементов;
  • Git — для контроля версий;
  • GitHub — для хранения и публикации проекта.

О работе над проектом

В ходе разработки были созданы семантическая HTML-структура, многостраничная навигация, каталог товаров, форма заявки, модальное окно и состояния интерактивных элементов.
