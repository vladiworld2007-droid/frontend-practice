# Статическая проверка проекта

Это **не Lighthouse-отчёт**. Автоматизированный запуск браузерного Lighthouse здесь не состоялся.

Проверено по исходным файлам:
- на каждой странице ровно один `h1`;
- локальные ссылки на файлы и ресурсы разрешаются;
- у всех `img` есть атрибут `alt`;
- поля имеют связанные `label` (кроме скрытых и кнопок);
- JS-файлы прошли `node --check`;
- в HTML подключены `js/data.js`, `js/main.js` через `defer`;
- изображения имеют `srcset` и `sizes`.

Для завершения ПР №13 требуется реальный аудит Chrome Lighthouse категории Accessibility. Сохраните `accessibility-report.html` или `accessibility-report.png` в эту папку.
